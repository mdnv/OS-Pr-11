## Быстрый запуск (Ubuntu 22.04 / 24.04, VirtualBox)

Откройте терминал **в Ubuntu**, распакуйте ZIP и перейдите в папку `OS_Practice_11_Ubuntu`.

```bash
cd ~/Downloads/OS_Practice_11_Ubuntu  # замените путь, если распаковали в другое место
bash setup_ubuntu.sh                  # установит Python, GCC, venv и matplotlib
bash run_ubuntu.sh                    # выполнит A+B+C, тесты и график
```

Для повторного запуска достаточно `bash run_ubuntu.sh`. При установке Ubuntu попросит пароль для `sudo`. **Не используйте `sudo pip install`**: зависимости устанавливаются в `.venv`.

Контрольная строка: `7 0 1 2 0 3 0 4 2 3 0 3 2 1 2 0 1 7 0 1`.

| Кадры | FIFO | LRU | Optimal | Clock |
|---:|---:|---:|---:|---:|
| 3 | **15** | **12** | **9** | **14** |
| 4 | 10 | 8 | 8 | 9 |

**Почему при 6+ кадрах 6 отказов?** В контрольной строке всего 6 различных страниц, значит после первой загрузки всех страниц заменять ничего не нужно.

**Аномалия Белади:** в строке `1 2 3 4 1 2 5 1 2 3 4 5` у FIFO 9 отказов при 3 кадрах и 10 при 4. FIFO не стековый алгоритм. LRU и Optimal — стековые алгоритмы: при увеличении числа кадров отказов не становится больше. Clock тоже может показать аномалию.

**Локальность:** при 1000 обращениях к 20 страницам и 5 кадрах последовательность с повторными запросами к близким страницам вызывает меньше отказов, чем случайная. Зафиксирован `seed=5`.

## Уровень C: Ubuntu VM и swap

Основная программа запускается **без root**:

```bash
gcc -std=c11 -Wall -Wextra -O2 -o faults level_c/faults.c
./faults
```

`malloc` запрашивает 64 MiB; запись в каждую страницу вызывает в основном лёгкие (`minor`) отказы; `major` могут остаться равны нулю. `/proc/self/stat` показывает суммарные счётчики Linux. Время обхода по строкам обычно меньше обхода по столбцам из-за локальности кэша. **Точные числа зависят от VM, ядра и размера страницы.**

Опыт с **пробуксовкой** — отдельный необязательный эксперимент. Он ограничивает память только тестового процесса через cgroup v2, может временно тормозить VM или завершиться OOM. Сначала сделайте снимок VM (snapshot), затем:

```bash
bash vm_info.sh                  # проверьте: swap активен, cgroup v2 доступна
bash level_c/linux_vm_demo.sh   # только Ubuntu VM, нужен swap и подтверждение YES
```

Если swap выключен, не включайте его без понимания состояния диска VM: инструкция и объяснения — `level_c/NOTES.md`. **Скрипт не включает swap автоматически и не меняет настройки памяти всей системы.**
